# 현장 일정 날씨판

오늘 현장 일정과 지역별 날씨를 한 화면에서 보고, 날씨 때문에 주의 · 중지를 검토할 일정을 표시합니다. (교육용 가상 데이터)

## 여는 법
1. Supabase 프로젝트의 SQL Editor에서 [setup.sql](setup.sql)을 실행합니다. `wx_tasks` 표와 기본 일정 6건을 만듭니다. 재실행해도 기본 일정이 중복되지 않습니다.
2. [config.js](config.js)의 두 줄에 프로젝트 주소와 공개용 publishable 키(또는 기존 anon 키)를 입력합니다. secret·service_role 키는 사용하지 않습니다.
3. 배포 주소에서 열거나, 인터넷에 연결된 PC에서 `index.html`을 엽니다.

일정은 Supabase에서 읽고 추가합니다. 다른 브라우저에서 새로고침하면 같은 목록을 볼 수 있습니다. 기존 `data/tasks.json`과 브라우저 저장 일정은 읽거나 자동으로 이전하지 않습니다.

교육용 공개 표이므로 주소와 공개용 키를 아는 누구나 가상 일정을 조회·추가할 수 있습니다. UPDATE·DELETE는 허용하지 않습니다.

## 확인 방법
- T-01: SQL 실행·연결 설정 후 기본 일정 6건이 나타나는지 확인합니다.
- T-02: 일정을 추가하고 다른 브라우저에서 새로고침하여 같은 일정이 보이는지 확인합니다. 저장 실패 시 입력이 유지되어야 합니다.
- T-03·T-04: 날씨 표시와 `?test=wind`의 고소 일정 판단을 확인합니다.
- DB 제약: SQL Editor에서 지역을 '서울' 또는 구분을 '기타'로 INSERT하면 CHECK 제약 오류가 나야 합니다.
- '오늘 판단 md로 저장' 버튼으로 현재 표와 판단 기준을 내려받습니다.
